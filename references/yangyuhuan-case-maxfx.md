# 杨玉环·特效拉满单实录（2026-10-28，turbo 翻车 → Q8 30步验收通过）

> 需求原话要点：「直接特效拉满 游戏特效加一些人物的元素进去」「人物精修」「主角灯光」「大胸 瘦腿 吐舌头」→ turbo 版验收后改「不要吐舌头了 然后其他不变 用q8 30步来生成」。
> 背景：工业风仓库棚拍坐姿持琵琶 ×3（同人同套），背景虚化保留未替换。

## 1. 「游戏特效 + 人物元素」写法（强档，Q8 验收三张全通过）
按角色技能机制写特效，不写通用光效堆砌。杨玉环=琵琶乐师（官方技能：霓裳曲音波 / 胡旋乐 / 长恨歌）：
- **琵琶音波**：琴弦泛起金色音波涟漪，三道半透明青绿色音波弧线从琴身向外扩散，像拨弦声浪可视化，边缘带细小金色音符与光点
- **长恨歌绽放**：青绿与粉色光带如霓裳羽衣环绕人物旋转飘舞，粉白花瓣与光尘漫天
- **飘带元素**：肩臂丝带被琴音带起环绕飘扬，带尖散碎光点
- 通用收尾：蓝白金色光尘粒子大量环绕漂浮
每条特效块末尾带「以高精度3D游戏CG质感呈现…不出现任何法阵、光环阵列或符文图案」兜底（挤压法）。

## 2. turbo vs Q8 服从性对比（本单新证）
- turbo 16步三张：_001 琵琶背后**法阵乱入**；_002/_003 **吐舌头未执行**（神态小概率丢失）。
- Q8 30步三张（同词删吐舌条）：零法阵、神态端庄、大胸瘦腿/追光/精修/琵琶完整全到位。
- 结论：**禁令类（别画X）与神态类（吐舌/闭嘴/眼神）指令，turbo 服从性明显弱于 Q8**——与「turbo 细节上限低」是两个独立维度。turbo 只作快出草稿看构图；验收级交付或含禁令/神态指令的单子直接 Q8。

## 3. 神态类小改的重跑口径
用户中途撤指令（「不要吐舌头了 其他不变」）：删对应条目、其余逐字不动、按当前指定档位**整单重跑**——不拿旧成图局部再生成。jobs.json 写入时可加 `assert "吐" not in text` 防回归（同毛孔防回归手法）。

## 4. 王者官方资料查证补充（GBK 解码坑）
- `herolist.json` 是 **GBK 编码**：`curl | json.load(sys.stdin)` 直接 UnicodeDecodeError。正解：落盘后 `json.loads(open(p,'rb').read().decode('gbk'))`。
- `herodetail/<ename>.shtml` 正文同样 GBK：`raw.decode('gbk','ignore')` 再剥标签。
- 杨玉环 ename=176；herodetail 页有完整技能文本（霓裳曲/胡旋乐/长恨歌），特效写词直接从技能名+描述取材——「特效拉满+人物元素」的词源就是官方技能描述。

## 5. 显存部分 offload = 慢而活，不是死锁（判读口径）
Q8 首张载入日志 `loaded partially; 2063MB usable, 1906MB loaded, 5589MB offloaded` → 单张 30-40min（正常约 15min）。判读三件：
- 功耗 45-70W 波动 + GPU 100% + 最终出图 = **在跑，只是慢，等，别 interrupt**。
- offload 死锁判据（0 进展 + 功耗恒定 50-65W + 无新输出）才 /free 重提。
- 触发场景：turbo 批刚跑完立刻切 Q8，显存碎片未清 → 首张 partial offload。预防：**档位切换前手动 POST /free 一次再提交**。
