# 大乔单 v2 实录（2026-10-28）：高P口径、过目门、元素禁令、坐具替换、背景清理

> 承接 `qwen21-prompt-obedience.md`（服从性缺陷）与 `scenes.md`（场景替换）。本单用户实锤的口径修正与写法；v2 四张待组装执行（§8）。

## 1. 提示词过目门（用户实锤：「为啥没给我看提示词」）
- 大乔四张**全新**提示词未过目直接提交 → 用户质问并要求「全停了看看提示词」。
- 规则：全新稿（新图/新需求/新场景，用户从没看过的）**必须先过目拍板再提交**。免过目仅限用户当轮明说；他对「改完的提示词」有常设豁免（原话「你改完提示词直接用turbo跑。不用再给你看改完的提示词了」）——豁免覆盖**已过目稿的改完版**，不覆盖没看过的全新稿。已过目稿增量小改+用户说「继续/重新跑」→ 直接跑，不必整稿重贴。
- 用户要求停看词的操作序列：`POST /interrupt` → `POST /queue {"clear":true}` → **kill cos_batch.py 进程**（脚本不死会把下一张继续提上去）→ 贴全文 → 等拍板重提。

## 2. 质感口径按单走：真实毛孔 vs 高P瓷感
- 实锤：甘雨单「不够真实」→ 保留真实毛孔；大乔单原话「皮肤有真实毛孔 四张图这个都不要 我要高P图的」。
- **口径是单子级属性**：每单按用户最新明说选开篇锚点，别把上一单带进下一单；没明说先问。
- 高P开篇锚点（大乔单实装）：
  > 真实相机拍摄的实景照片，真人实拍，人物为高P精修风格——皮肤瓷感细腻通透、无瑕平滑，妆容精致，整体质感干净高级，像精修过的高品质人像写真正片。
- 高P精修条：肤质瓷感细腻、白皙透亮肤如凝脂、无瑕平滑零瑕疵；**全稿砍掉毛孔/细腻起伏字样**。
- 真实感锚点（甘雨 _002 实装，治「背景假/光线假/塑料感」）：保留真实毛孔与细腻起伏+布料真实褶皱+物件老化痕迹（窗纸发黄、木框掉漆、瓷瓶开片）+光源有明确来源方向、影子统一。

## 3. 全批次元素禁令（obedience #1 再证实）
- 用户原话：「可以水元素多一些 但是不要出现法阵」。
- 升级写法：**全稿连 X 的名字都不出现**（连「不出现法阵」都不写，写了反而给落点）；落点区域写成具象终态——地面→CG质感水面+荷叶荷花+圈圈涟漪，水元素特效全走涟漪/水花粒子/光尘/雾气，法阵无处可画。

## 4. 坐具/道具替换：别提旧道具（存在性锚定）
- 需求：图2 白圆毛毯→坐荷叶；图3 黑梯凳→坐盛开的荷花。
- 写法：旧坐具一字不提，只写新坐具承托终态（「坐在宽大厚实的荷叶上，叶片边缘微卷，自然承托身体重量微微下凹」）。「把A替换成B」句式弱（两个都画/都消失），写「画面里是B的终态」强。

## 5. 背景清理模块（保场景清杂物 ≠ 场景替换）
- 需求形态：「灯具背景人物去掉，只保留空场地」——场馆透视/地面/建筑结构保留，清走人/灯架/杂物/水渍。
- 写法：列全清单+存在性收尾（「移除背景里的灯架、柔光箱、反光板、电线与所有人员，地面水渍清除，画面中只有这一位人物与干净的场地」）。
- 验收坑：vision 可能把保留的建筑结构（水泥柱/横梁/EXIT牌）报成「清理未完成」——验收准绳是用户口径（人和灯具清空），建筑结构本就要留。

## 6. 主角灯光
- 写法：「一束柔和而集中的主角追光从侧上方打亮人物，人物在光束中明亮突出，背景相对压暗，光束边缘有细腻的体积光」，可配轮廓光勾边与背景分离。

## 7. 档位与步数（本单拍板流）
- turbo 16步（四张成图用户自己删光弃用）→ Q8 40步（甘雨单质感认可，默认档）→ Q8 20步对比样（全程实测 ≈15 分钟含模型重载，_007）→ **大乔 v2 定档 Q8 30步**（用户新点档，耗时未校准）。
- jobs.json per-job `"model":"q8","steps":30`。用户会自己清输出夹废片——断点续跑「已有成图跳过」对已删文件自然失效，同名重提不冲突。
