# 识图判读与背景选型实证（2026-10-25 云缨单张批次）

三条用户当场纠正 + 一条搜索实证，适用于所有「识图报认定」步骤。

## 1. vision 识图会被自信地带偏——文件名/夹名是用户给的角色断言

实测：拍摄原图（红衣武服+黑腰封+厚底高跟+金红长柄法器，广角仰拍蹲姿）被 vision 判成崩坏：星穹铁道·花火，且置信度报「确定」。用户一个字拍板：云樱（王者荣耀·云缨）。

规则：
- **文件名/夹名与识图结论冲突时，文件名优先**——那是用户给的断言；但**仍要开口让用户一句话确认**，摆出冲突点+关键判别依据（鞋/武器形制/配色），让他选，别自作主张改。
- vision 的「确定」不可全信：COS 服化道与立绘常有出入、热门角色互相撞脸（红白金配色+黑腰封在云缨/花火两端都成立）。
- 错认角色的代价全在后端：特效选型（云缨=掠火枪意 vs 花火=戏剧彩纸）、背景（长安街巷 vs 舞台）全歪。

## 2. 「瑕疵」只描述客观画质，不断言「已精修/精修过」

实测：识图报告写「画质极高、皮肤经过精修」→ 用户纠正：**这不是精修，是拍摄原图**。

规则：
- 识图的瑕疵栏只写可核验的客观项：清晰度/噪点/色偏/油光/碎发/布料毛边。
- 原图还是精修图**由用户说了算**，识图不下这种结论。
- 用户说「拍摄原图」+「人要精修」→ 精修是本单核心需求，精修条目要写足（皮肤干净通透但保留真实肤质纹理、去油光、理碎发、布料整洁），而不是默认「原图已美颜、少修」。

## 3. 背景重构按「角色设定场景 + 姿势动势」选，且与特效同源

用户原话：「背景要符合人物和人物动作」。

实测选型（云缨，王者荣耀设定：长安大理寺总捕头，大招「掠火·夜杀」）：
- 背景 = 唐代长安夜市街巷（远处牌楼+灯笼虚化光斑+青石板反光+薄雾）
- 特效 = 火焰爆发组合（effects.md 组合模板）：枪头火焰（强）+ 火星粒子（中）+ 冲击波（中）+ 冷暖电影调色
- 两者同源于「掠火·夜杀」的设定，不会打架。

规则：先定角色设定 → 背景与特效**一起选**（同一设定源），别各自挑好看的。姿势动势决定特效落点（蹲姿持枪上举 → 火焰顺枪身卷动、枪尖拖火星），背景只负责世界观与氛围光。

## 4. 角色资料联网搜不到是常态

实测：bing 对「云缨 原皮 特效/背景故事」两类查询全被「王者荣耀官网/云游戏/云原神」词条污染，零有效结果。国产热门游戏角色搜不出资料时，按已知设定推进、不阻塞，别换词反复烧搜索次数。

## 交付判据

- 启动询问按「备问清单」收敛后，用户一口气答完（角色/原图定位/背景要求/精修要求/特效档位）→ 直接进提示词组装，不再追问。
- 提示词编号条目顺序：精修 → 背景重建 → 主特效 → 粒子/辅助特效 → 调色 → CG质感措辞；「禁止」段收尾（变脸/变人/变款/变形/火舌烧身/过曝）。此结构本轮一次过审。
