# 换背景单（场景替换）——选型规则与提示词调整法

> 2026-10-26 云缨单首次实践（`Desktop\罗莱短剧\coser测试\王者荣耀-原皮云樱.png`，2628×2160 横图，PIL 实测）。提示词已组装给用户过目，**尚未出图验收**——复用前先核该单产出效果。

## 需求形态
用户原话：「背景替换成和云缨身份相符的 但是也要根据动作来」+「人物是原图未修的 要精修一下」+「特效强」。= 场景替换 + 人物精修 + 强档特效三合一，选型有硬规则，不是挑个好看场景就行。

## 双匹配选型（先后固定）
1. **身份匹配**：查角色设定找「设定地标」。云缨（王者荣耀）= 长城守卫军 → 山巅长城烽火台/烽燧。角色资料来源 = 识图结论 + 联网搜（SKILL.md 第 2 步 fallback）。
2. **动作匹配**：按识图记下的姿势动势定「站位与前景」。弓步突刺 + 发丝后扬 → 站垛口前面向开阔方向，强化冲锋气势；站立持械 → 据守/瞭望位；舞蹈 → 花瓣雨高处舞台感。
   只做身份不看动作 = 错配（等价于三维选型里「人在跳舞却画地面阵」的老坑）。

## 衔接三原则（降违和）
- **同风格族**：新背景与原场景同族——古建→古建实景，不跨现代；「背景出现与身份不符的现代元素」写进严禁区。
- **透视延续**：人物脚位、身体朝向、镜头角度与原图一致；新地物按原图透视摆放（例句：「人物站在烽火台垛口前，透视与站位延续原图」）。
- **光线可升级**：换背景单里全局光照/色温允许随新场景改（阴天平光→暮色金红天光）——这与纯精修单相反，纯精修的光线在「保持不变」区。

## 提示词模板调整（相对 scripts/qwen21_img2img.py 默认模板）
- 定位句：写「背景替换为：XX + 时辰 + 远近景层次」+ 一句身份理由 + 一句动作理由（让用户能直接看懂为什么选这个背景）。
- 「保持不变」区：**删「背景内容不变，全局光照、环境氛围与色温不变」整行**，改写为「动作姿势保持原样」「身体朝向与镜头角度不变」；保真四件（五官/身材/服装/道具形制）原文照留，一字不砍。
- 处理内容编号条目照常四条：人物精修 / 全局氛围 / 特效档位 / 景深。
- 一致性句不动。

## 坑：光源词要换绑新背景
换背景后别再引用旧背景专属物件当光源——云缨单初稿写了「石灯笼等暖色光源点亮」，石灯笼属旧庭院景，全量换背景后它已不存在。新场景光源写新场景自带的：烽燧火光 / 晚霞侧逆光 / 城台火盆。旧景物件残留词有在空背景上画出违和漂浮物的风险。

## 出图参数
与编辑链同款、无特殊：8 节点编辑链、denoise=1.0（latent 拼接语义见 qwen21-img2img-api.md）、resolution=2048、40 步、4060Ti 约 19 分钟/张。横图先用 PIL 量原图尺寸（vision 报尺寸不可信）：2628×2160 输入精度足够 2K，无需预放大。

## 首例提示词全文（云缨·长城烽火台版，待出图验收）

《王者荣耀》云缨·原皮 COS 照——场景替换 + 人物精修 + 强档特效后期

背景替换为：山巅长城烽火台，暮色将至，远处层叠山峦与晚霞。与人物身份相符：长城呼应云缨的长城守卫军身份，与原照片同为中式古建风格衔接自然；与动作相符：弓步突刺、发丝后扬，烽燧城台与漫天红叶强化冲锋气势，人物站在烽火台垛口前，透视与站位延续原图。

保持不变：
- 人物面部与五官与原图完全一致：眼型、双眼皮、唇鼻、下巴轮廓逐项复刻，不变成另一个人
- 身材按原图真实轮廓复刻：腰臀比、腰线、肩宽、腿长对照原图，不美化不平匀化
- 人物穿着原图那套云缨原皮铠甲短裙与金饰，形制、配色、材质与原图一致；红色高马尾发型与刘海保持
- 动作姿势保持原样：弓步蹲姿、双手举枪、身体朝向与镜头角度不变
- 长枪形制与原图一致：红色枪杆、金色火焰纹枪头、红缨

处理内容：
1. 人物精修：皮肤干净通透、轻磨皮、妆容清晰、发丝层次分明；服装材质质感增强，红色绸缎光泽、白色提花暗纹、黑色皮革与金色金属件清晰锐利；矫正广角畸变让画面边缘线条自然；清除右下角地面杂草。
2. 全局氛围：阴天平光升级为暮色将至的金红色天光，长城以北云层压城，人物受晚霞侧逆光，暖色光源点亮，冷暖对比增强，画面更有史诗感。
3. 强档特效：枪头红金火焰枪芒爆发，火焰沿挥枪轨迹拖尾，火星与红叶漫天飞舞，发丝与裙摆被带起的风向右飘，地面被火光照亮。
4. 景深优化：背景远山虚化，主体人物清晰。

严禁：面部重绘、改变五官身材、更换或增删服装配饰、改变动作姿势、改变长枪形制、背景出现现代元素或与古风不符的物体、人物变国漫画风。

一致性：所有修改区域光影、噪点、色温与成图整体统一，新增元素符合照片原有透视。
