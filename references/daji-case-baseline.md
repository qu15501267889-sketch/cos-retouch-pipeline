# COS 成片验收基准（内参）

按妲己单系列实录沉淀。成片落盘后先自查再交付。

## 尺寸验收（唯 PIL 实测）
- vision 报尺寸不可信（曾把 1760×2368 说成 4608×3456）。
- `from PIL import Image; Image.open(p).load()` 既能验尺寸又能验文件完整（断电半图会 load 失败）。

## 关键教训（已分别写入对应 reference，此处汇总索引）
1. 坐姿误判 → 识图必须二遍细识支撑关系（vision-id-and-background-selection.md）
2. 坐腿姿势自作主张被否 → 姿势映射用户点名（background-replacement.md 叙事人物替换单）
3. 皮肤偏黄 → 冷白强化词叠加路径（portrait.md 美白升级句）
4. 踩背悬空 → 物理接触写实句（background-replacement.md）
5. 三次漏精修 → 触发铁律（portrait.md body_sculpting 章节）
6. 特效最弱档 = 删除条目而非改弱措辞（effects.md 轻档定义）
