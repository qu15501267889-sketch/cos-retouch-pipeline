## 2. 冰锥特效三落点写法（v2 验收全中的具象终态）
1. **地面**：大量尖锐修长的冰锥从雪地四周爆发式破土生长，簇拥环绕人物，高矮错落，尖端斜指天空与人物，锥身内部寒光流转，寒气与冰屑沿锥尖升腾。
2. **头顶上空**：数枚大型冰锥悬浮倒悬，锥尖朝下，随时将落未落——大招压迫感的叙事句。
3. **动势落点**（人物自身）：抬起的指尖寒冰凝结+寒气光点向天空流转上扬——把特效锚在原有施法动作上，不新增动作。
通用收尾沿用 effects.md 冰霜融入写法（淡青色冷调补光/透明反光层次/CG 质感句）。
**注意**：场景段保留「雪地/积雪地面/雪原」无碍——「换成冰锥」换的是特效层，不是雪地场景本体（用户没说换场景）。vision 验收确认「漫天飞雪特效清零、冰锥为主体、雪地仍在」达标。

## 4. 中断重启恢复姿势（turbo 批量 → q8 单张超时 → 用户重启 → 重跑成功）
- **现象**：v2 q8 30步首跑在 turbo 批量跑完后提交，25min+ 无完成（疑 partial offload 慢速推进型，同 Pitfall #13）；用户手动重启电脑。
- **恢复 = 三查一提交**：
  1. `curl http://127.0.0.1:8188/system_stats` 探活（重启后服务自起）；
  2. 查交付夹无同名成图（cos_batch 断点续跑按「同名文件存在」跳过，没成图就不会误跳）；
  3. jobs.json 内容确认还是目标任务（没被覆盖就不用重组）；
  4. 直接原样重跑 `cos_batch.py edit`。实测重启后干净显存 q8 30步 ≈13-15 分钟完成。
- **教训**：档位切换（turbo→Q8）前手动 POST /free 一次再提交；长跑异常时先看 GPU 功率判推进 vs 死锁（0 进展+功耗恒定才 interrupt）。
