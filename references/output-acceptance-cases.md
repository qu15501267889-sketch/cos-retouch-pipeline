## 案例 2：浅蓝 Lolita + 木刀（芭蕾 Arabesque 抬腿姿）

- 识图：vision 模型声称「蔚蓝档案音濑莫妮卡」又扯「便利屋68」——**自相矛盾，不可信**。只采信可核验特征：浅蓝双马尾 + 蓝瞳 + 猫耳发饰 + 白/浅蓝 Lolita 蓬蓬裙 + 白蕾丝长筒袜 + 木刀。
- 用户追加要求：①元素按 agent 理解 ②**场景替换掉漫展**（原背景是展馆木地板+钢结构顶棚+焦外光斑）③修瑕疵且**按 skill 本身提示词** ④Qwen2.1 本地跑
- 选定方案：场景 → **月光雪境**（配冷蓝白主色、雪地反光补轮廓光）；特效 → 冰晶气流绕木刀 + 裙摆云朵化 + 发丝冷色光尘；修脸 → template.json 的 skin/blemish/eyes/hairline 原文
- 提交：`images.image_1` 图生图接法一次成功，未报错 → 验证了 API 接法正确
- 出图：1664×2496 RGBA（PIL 实测），约 19 分钟（seed 688843）
- 结果：**5 项全中**——漫展背景成功替换为月光雪境（雾凇枝影/飘雪/冰雪地面反光，漫展彻底消失）；木刀周围淡蓝冰晶气流+光点星芒；裙摆随抬腿蓬开有动态；五官无漂移无换脸；手指正常。
- 问题：
  - **木刀溶解**：刀身被重绘成断续的「悬浮矩形木块」，运动道具部分被吃 → 对策已入 SKILL：手持/挥舞道具在「保持不变」段加「道具形制完整连贯，不断裂不溶解不变形」，待复测
  - **面部瓷感**：磨皮过重 → **用户拍板接受（2026-10-25 原话「没事这样挺舒服的」）**：纯瓷感但五官未崩 = 默认保留不重跑，写进 SKILL 自查规则；仅用户点名要毛孔质感才重跑
  - 小瑕疵：猫尾巴根部与身体衔接生硬（贴图感）、左鞋鞋带略乱、脚与雪地衔接稍硬

## 验收方法

- **尺寸必须用 PIL 实测**，不能让 vision 报——vision 会把 1760×2400 说成 4608×3456。
- 视觉评价按项打分：特效是否到位 / 保真是否崩 / 有无 AI 手 / 道具是否完整 / 背景融合度（含漫展残留检查）。
- 用户验收标准是**他真实眼见**，不是我自称完成；他会亲自删图（第 7 步交付后自由删图即验收动作；2026-10-26 起无超分阶段）。
