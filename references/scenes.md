# 场景替换

用户要求换背景（「不要漫展场景」「换成卧室」「背景太乱」）时启用。替换段落写成完整句子编进「处理内容」第 1 条。

## 三条选择铁律

1. **配角色主色调**——冷色服装（冰蓝/银白/黑紫）→ 雪境 / 月夜 / 冰湖 / 赛博街夜；暖色服装（橙红/金）→ 夕阳 / 灯火 / 枫林；红金 → 舞台追光 / 枫林夕照
2. **配姿势动势**——抬升/跃起 → 开阔纵向场景（天空、山巅）；战斗姿态 → 有张力的场景（废墟、战场）；舞蹈/换腿姿态 → 舞台 / 花瓣雨；静态站立展示 → 室内精致场景（卧室 / 梳妆区 / 落地窗前）
3. **保原透视**——替换场景的地面线、灭点、相机俯仰角必须与原照片一致，人物脚部接触面合理不悬空

## 替换句式

```text
替换背景场景：把{原场景}背景替换为{新场景}——{2-3个画面细节}，{色调}与人物{呼应点}统一。新场景的透视与原照片的相机角度、{俯仰关系}保持一致，人物脚下的{原地貌}自然衔接为{新地面}。
```

**实例（卧室 · 托盘站姿）**：
> 替换背景场景：把漫展场馆背景替换为典雅卧室——身后是铺着白蓝色床品的大床与落地飘窗纱帘，前景一角是虚化的梳妆台边沿，低饱和蓝白色调与人物冰蓝假发、黑白女仆装呼应统一。新场景的透视与原照片的相机角度、俯仰关系保持一致，人物脚下的混凝土地面自然衔接为卧室浅色木地板。

## 配套前景/后景（按姿势配，别只换背景板）

换场景不只是刷背景墙，要补**层次**才不假：

- **前景**（虚化，压画面边缘）：梳妆台边沿 / 纱帘一角 / 门框 / 花枝 / 飘落花瓣 / 前景光尘
- **后景**（对应场景纵深）：床与飘窗 / 镜与衣柜 / 树干与远景山 / 舞台背幕 / 霓虹招牌
- **光源方向必须与原图主光一致**——原图柔光箱在右前方，新场景的光也从右前方来，否则人物受光与环境打架

## 禁止

- 背景出现原场景残留元素（漫展桁架 / 人群 / 光箱边角）
- 新场景光源方向与原图主光相反
- 地面线错位、人物悬空、灭点不一致
- 换场景同时改人物姿势或服装

## 场景替换必须让用户知道换成什么

提示词过目环节天然覆盖。用户点名场景 → 直接用他点名的；用户只说「不要 X」→ 按三条铁律选 1-2 个候选给他挑，不擅自定。
