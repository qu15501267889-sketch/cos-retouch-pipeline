# 特效词库 · 数量化身体部件（九尾/多翼）条目

> 本文件是 `effects.md` 的增补条目（兽尾/狐尾 + 写法五律），2026-10-26 妲己九尾单组稿沉淀。
> 详细写法细则与组稿实录见 `counted-body-parts.md`；本文件只收词库本体条目。

## 八·五、兽尾 / 狐尾（新增身体部件）

- **视觉描述**：{腰后}展开{九条}{金白渐变}的毛绒{狐尾}，呈扇形如开屏般在身后铺开，毛发蓬松根根分明，尾尖泛白，边缘两三条绕至身侧微微上扬，形态完整连贯
- **融入写法**：尾根衔接腰后服装下缘自然无痕，不悬浮不贴片；被身后主光源照亮泛柔光；地面为镜面/水面时同步补尾部倒影
- **强度**：轻＝一两条尾影若隐若现 / 中＝五尾清晰展开 / 强＝九尾满幅如孔雀开屏
- **变体**：九尾狐、单猫尾、恶魔尖尾、机械装甲尾、龙尾、羽尾

## 数量化部件写法五律（九尾/多翼等带数量要求的部件）

1. **数量锚定**：数字直接写进视觉描述（「九条」），不写「许多/多条」——数量词决定成图条数
2. **根部衔接**：「根部衔接{腰后/肩胛}服装下缘自然无痕」，防悬浮贴图感
3. **遮挡守卫**：严禁段加「{部件}不遮挡人物面部、手部与服装主体」
4. **连贯句**：部件条目带「形态完整连贯」（同道具保真句，防部件被重绘吃掉溶解）
5. **光影归属**：部件受光与画面主光一致；有倒影面时部件倒影一并写
