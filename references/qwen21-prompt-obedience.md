# Qwen-Image-2.1 提示词服从性缺陷与修复（2026-10-27 妲己单 _05 实测沉淀）

> 收「模型不照提示词办」类问题。与 qwen21.md 写词纪律互补：那份管怎么写词，这份管写了也不听怎么办。
> 状态：✅=已实测确诊；⏳=修复法待验证（v3 四张 _06-_09 出图后回填结果）。

## 1. 存在性否定禁不住（「不出现X」照样画）✅
- 实测：v2 提示词条目+严禁段双锁「地面不出现任何法阵图案」，_05 成图仍画金色法阵（vision 确认）。
- 根因：cfg=1 无负词，正向里的否定存在句约束力最弱，严禁段写了也白写。
- 修复法 ⏳：**正面描述挤压语义空间**——把该区域写成无 X 的具象终态（「地面为纯净的深色镜面石材，光滑如镜无任何图案纹路」），让 X 在正向描述里没有落点；严禁句保留但只当兜底。
- 适用：法阵/光环/背景人物/水印/杂物，一切「别画出来」需求。

## 2. 只写「与参考图一致」锁不住颜色 ⏳(诊断✅)
- 实测：_05 丝袜变纯白。原图实为右腿黑丝/左腿肤色长筒袜（识图已记录），提示词只写「大腿袜叠搭」没带色 → 模型自行归一成白。
- 根因：款式词不带色相时，模型向画面主色调/常见搭配漂移。
- 修复法 ⏳：保真段逐件写明颜色（「丝袜颜色与参考图完全一致：深色丝袜，不变成白色或浅色」），严禁段再锁一次（「丝袜颜色不得变为白色或浅色」）。
- 规则：识图清单里的服装颜色是硬信息，组稿必须进保真句——款式与颜色是一件事，不能只带款式。

## 3. 细节修改写「动作」不如写「终态」⏳(诊断✅)
- 实测：「丝袜褶皱抚平/全部抚平」成图膝盖仍有堆叠褶皱。
- 修复法 ⏳：写可见终态而非处理动作——「膝盖处袜面平滑无堆叠无褶痕，脚踝处平整无堆积，只保留极轻微自然穿着张力」。
- 通则：模型对「消除X」类动作句弱，对「画面长什么样」的具象终态强。精修/特效/场景条目全适用。

## 4. 原生 4K 结构性 OOM ✅
- 实测：resolution=4096 → KSampler `Allocation on device 0 would exceed`（4060Ti 8G，2026-10-27）。latent 为 2048 档的 4 倍，与 8K tiled 同性质封死。
- 结论：原生上限 2048 档；4K 只走 `upscale-4k-tiled.md` 切块超分（_02_4K 全程 34 分钟实测，远快于 2-3 小时预估，restore 16 步约 4 分钟/块）。
- cos_batch.py 已支持 jobs.json per-job `resolution` 字段（默认 2048）；8G 卡上别填 4096。

## 5. 语义歧义：用户对旧元素说「替换成X」可能是「删掉」✅
- 实测：用户说「头上的光环替换成游戏狐火的颜色」，agent 读成保留光环改粉紫色；下一轮用户「头上光环还是没去掉」才暴露原意=删除。
- 规则：用户对**上一轮点名要动的元素**下指令且「替换/改」存在保留与删除两种读法时，提示词过目稿把该项取向单列写显眼（如「光环：整条删除」），让用户第一眼就能纠正，别靠猜。

## 6. 缺陷确诊 → 立即停旧队列 ✅
- 用户报的缺陷源于提示词本身 → 同词的未跑完任务全是废片：先 `POST /interrupt` → `POST /queue {"clear":true}` → `POST /free`，修词改 jobs.json 重提。
- 已知缺陷提示词跑完 = 白烧卡（_06-_08 旧词任务就是这么停的）。

## 7. 同词多种子选图 ✅
- 用户说「多跑几张看看效果」→ 同一提示词一字不改 × N 个不同 seed，out_name 序号递增（_06/_07/_08/_09），落盘后用户自由挑。
- seed 逐张不同写进 jobs.json；串行照常（每张之间 /free 防死锁）。


## 8. 丝袜修复的两难：褶皱与袜色是同一根旋钮 ⏳(诊断✅ 2026-10-27 _07/_08 两轮)
- _07：褶皱条写「袜面平滑无堆叠」→ 模型把「平整」执行成「脱掉/抹掉织物」——左腿袜变浅灰哑光、右腿肤色袜直接消失成裸腿。存在性锚定缺失（只有颜色句没有穿着状态句）。
- _08：补了存在性锚定（穿着状态本身不变/不得变裸腿）+ 褶皱条加「保留半透明质感与织物纹理」前提 → 袜子回来了，但**脚踝褶皱回来了**（vision 确认脚踝挤压褶痕清晰）、袜色仍偏浅（RGB：原图双腿亮度≈70，_07=110/92，_08=109/93——半透明度上升=视觉变浅）。
- 根因：**「抚平褶皱」「保持半透明」「颜色不变深浅」三个目标在 5-10 denier 薄袜上互相牵拉**——褶皱本质是织物堆叠，模型压褶皱的最省力路径=减少织物量/降低不透明度；保质感句又把不透明度往下拉。纯提示词内无解，需要别的手段（局部遮罩编辑/参考图加权/分段两遍编辑：先全图修+再袜区局部锁色）。
- 待验证：_09 方案待用户拍板后跑。
