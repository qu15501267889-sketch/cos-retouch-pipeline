# COS 修图管线 · cos-retouch-pipeline

> 真人 coser 写真后期流水线 —— Hermes Agent 技能（Skill）
> **触发词：「你好cos」** · 输入图片路径 → 输出 2K 修图成片
> 全程本机 ComfyUI + Qwen-Image-2.1，API 提交，不碰用户活画布
> 版本 **v3.0.0**

---

## 它解决什么问题

COS 摄影后期（换场景 / 加特效 / 修脸）通常要手动开 ComfyUI 拼工作流、手写提示词、手动换图重跑。本技能把它固化成一条**七步管线**：agent 接到图片路径后自己识图、给认定结论、组装提示词、批量提交渲染、交付 2K 成片。

```
全夹图 → 逐张识图报认定 → 定改法定参数 → 提示词过目
      → 逐张串行 2K 编辑（每张之间释放显存）→ 落盘 + 清单交付
      （用户在输出夹自由挑选删除，无后续阶段）
```

**不做超分**（v2.1.0 起移除 8K 阶段）：交付止步 2K。外部超分模型（4x-UltraSharp / RealESRGAN）放真人脸必形变，永远别用。

## 两条铁律（最高优先级）

### 🔴 铁律一：每步结束必须停下询问用户
每一步做完必须停下来问用户，得到答复才进下一步。**严禁私自挑步、跳步、合并步、替用户拍板。**「继续」= 只推进到下一个检查点，不是「一路做完」。例外仅限用户单条消息明确授权「一路做完不用问」。

### 🔴 铁律二：全程禁止调用 memory 工具
执行本技能时严禁调用 agent 的个人 memory 工具（额度满时会陷入「add 超限 → replace 歧义 → 反复重试」死循环）。跨会话记忆一律走本技能自己的文件：用户口味 → `references/preferences.md`，流程规则 → 本 SKILL.md。

## 七步管线

| 步 | 内容 | 要点 |
|---|---|---|
| 1 | **启用** | 收到「你好cos」或「路径+后期意图」即进入，不寒暄 |
| 2 | **输入图片路径** | 扫张数自动判单张/批量；输出夹默认 = 图所在夹；读 preferences.md 命中偏好直接当默认 |
| 3 | **识图 + 报认定** | 角色（必标置信度：确定/疑似/认不出）、场景光线、服装、姿势、瑕疵清单、特效候选三维依据（角色元素+场景光线+姿势动势）；输入图自带 AI 痕迹必须如实告知由用户裁决；报「我认为这是 XX（置信度：确定）」等确认 |
| 4 | **定改法** | 用户说了照办；授权自拟则先给方案过目；**汇报必须同回合附上逐张全文提示词**；换场景按 scenes.md 三铁律；修脸措辞逐字引用 portrait.md（唯一权威源） |
| 5 | **定参数** | 只问 3 项：目标模型 / 特效档位（轻中强）/ 输出夹 |
| 6 | **生图** | 五段模板组装提示词，**逐张全文过目**（禁「同开头+差异」省略式）；确认后逐张串行，每张之间 `POST /free` 释放显存防 offload 死锁 |
| 7 | **交付** | 报告成功/失败/跳过清单 + 文件路径；逐张视觉自查（五官漂移必须报）；不做超分 |

每步收尾固定问句式见 SKILL.md「每步收尾必问句式」表，照抄不自由发挥。

## 执行模型（默认 Q8_0，turbo 仅点名）

| 档位 | 模型文件 | 加载节点 | 步数 | 耗时 |
|---|---|---|---|---|
| **默认 Q8_0** | `qwen-image-2.1-UC-Q8_0.gguf` | `UnetLoaderGGUFAdvanced`（float32/f16/true 三参数防黑图） | 40 步 | ≈19 分钟/张 |
| **turbo 速度档** | `rayQwen21_turboV13Int8convrot.safetensors` | `UNETLoader`（非 GGUF 节点） | 16 步 | ≈7 分钟/张 |

- turbo 快但细节/质感上限低（皮肤塑料感/毛发毛刺/特效贴纸感，蒸馏固有），仅用户点名使用。
- **禁止擅自切换默认模型** —— 默认档位变更必须用户拍板。

## 提示词五段模板

```text
你是Cosplay人像后期综合处理师。专业摄影棚人物全身人像，真实相机拍摄。对这张照片执行以下后期处理，只做下面明确列出的事，未提及的部分一律保持原样。

保持不变：
- 人物五官与参考图完全一致，眼型/双眼皮/唇/鼻/下巴轮廓逐项复制，不变成另一个人
- 动作姿势不变，构图取景不变
- 人物穿着参考图那套服装，与参考图一致
- <有手持/挥舞道具时>道具形制完整连贯，不断裂不溶解不变形
- 不做缩放、旋转、平移，保持照片原有透视关系

处理内容：
1. <做什么 + 在哪 + 画面长什么样 + 如何与原片融合，写成完整可读的中文句子>
2. <同上，按重要性从高到低编号>

严禁：<基础禁止项 + 各启用模块的专项禁止项，顿号连接>

一致性：所有修改区域光影一致、噪点一致，新增元素符合照片原有透视（灭点方向/相机角度/景深关系）
```

**硬纪律**：真人锚点双句齐上；保真四件（五官/身材/服装/道具）不可砍；cfg=1 负词无效一切约束写正向；词精简勿绝对词；以参考图为准；保真上限 = 参考图分辨率；三档特效措辞映射（轻/中/强）。

## 关键环境约定

- **ComfyUI**：`D:\AI\ComfyUI_windows_portable`，端口 8188，Qwen-Image-2.1 本地执行
- **显卡**：RTX 4060 Ti 8G —— 编码器 8.8G + 扩散模型 7.1G = 16.6G 远超显存，长时间运行会 offload 死锁，故**每张之间必须 `/free` 释放显存**
- **交付止步 2K**，不做超分；外部超分毁脸
